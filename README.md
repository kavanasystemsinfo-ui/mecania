# Mecania

Asistente IA para mecánica de coches. Proyecto de portfolio de Jorge Adán (Kavana Systems).

## Stack

- Java 21 + Spring Boot 3.4
- PostgreSQL 16 + pgvector
- Angular 21 (frontend, to be added)
- Docker + Docker Compose

## Getting Started

1. Copy `.env.example` to `.env` and fill in the values
2. Run `docker-compose up -d` to start PostgreSQL
3. Run `./mvnw spring-boot:run` to start the application
4. Access Swagger UI at http://localhost:8080/swagger-ui.html
